# Lyssa

> [!WARNING]
> This project is in its very early days and fully WIP.

## Features (none are working yet)

#### Prescription Handling

Dispense tracking, automatic reminders and full treatment history.

#### Prescription OCR

Automatically create a prescription with all the future dispenses.

#### Medication database

Getting medication data from the [french public database](https://base-donnees-publique.medicaments.gouv.fr/).

## Getting Started

1. If not already done, [install Docker Compose](https://docs.docker.com/compose/install/) (v2.10+)
2. Run `make start` to build & run fresh images
3. Go to `https://localhost`
